# 4. Assets & Lifecycle

## Asset identification

Assets receive sequential APEX asset tags, for example:

`APEX-000001`

Each asset also has a unique QR token.

## Asset profile

The platform supports an asset profile containing operational information and lifecycle-related data.

## Lifecycle

Lifecycle functionality covers:

- Asset lifecycle state
- Lifecycle events
- Assignment
- Check-in/check-out
- Replacement planning
- Warranty information
- Maintenance
- Issues/faults
- Asset history

## Assignment

Assets can be assigned individually and through bulk assignment workflows.

Assignment history is retained.

## QR

QR functionality provides a route into an asset's operational record. QR identifiers are unique and should not be manually duplicated.

## Asset deletion

Asset deletion should be treated as an administrative action. Before deleting important records, verify that the asset is not required for historical, audit, financial or compliance records.
