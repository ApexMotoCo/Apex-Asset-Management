# 7. Procurement & Suppliers

## Suppliers

Supplier records support:

- Supplier name
- Contact details
- Email
- Phone
- Website
- Notes
- Active/inactive state

## Purchase orders

Purchase orders support:

- PO number
- Supplier
- Status
- Order date
- Expected date
- Received date
- Line items
- Quantities
- Unit costs
- Total order value
- Links to assets where applicable

## Procurement dashboard

Management information includes supplier/order counts and procurement value summaries.

## Controls

Purchase-order data should be treated as financial/operational records. Changes should be auditable and supplier information should be kept current.
