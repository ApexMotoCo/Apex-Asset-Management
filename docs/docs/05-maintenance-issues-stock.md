# 5. Maintenance, Issues & Stock

## Maintenance

Maintenance records support:

- Maintenance type
- Status
- Scheduled date
- Completed date
- Next service date
- Assigned user
- Cost
- Notes
- Creator/update information

Supported maintenance types include:

- Service
- Repair
- Inspection
- Other

Supported statuses include:

- Scheduled
- In Progress
- Completed
- Cancelled

Maintenance reporting includes overdue, due-soon, open-repair and completed information.

## Issues

The issue workflow supports:

- User fault/issue reporting
- Administrative triage
- Repair workflow
- Issue state tracking
- Attention alerts
- Audit activity

## Stock

Stock functionality was introduced for:

- Stock summaries
- Stock movement history
- Check-out
- Check-in
- Bulk assignment

### Known status

The Stock page previously exhibited a problem and was deliberately left for a later health pass. Do not document it as fixed until it has been tested on the current v3 installation.

## Operational rule

Check-out/check-in and bulk assignment should be performed through the application so the related movement and audit information remains consistent.
