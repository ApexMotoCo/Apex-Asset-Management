# 8. Compliance & Documents

## Asset documents

The document register supports document categories such as:

- Warranty
- Certificate
- Inspection
- Invoice
- Lease
- Policy
- Other/reference documents

Records can include:

- Asset association
- Document reference
- Issue date
- Expiry date
- URL
- Notes

## Compliance

Compliance records support operational checks such as:

- Inspections
- PAT testing
- Electrical safety
- Fire safety
- Insurance
- Roadworthiness
- Data/security
- Custom compliance requirements

## Compliance monitoring

The system surfaces:

- Overdue compliance
- Upcoming compliance
- Expired documents
- Documents approaching expiry

The configured warning window should be reviewed in System Settings.

## Governance

Documents should be stored at an appropriate controlled location. URLs recorded in the application should point to the authoritative document rather than temporary local paths.
